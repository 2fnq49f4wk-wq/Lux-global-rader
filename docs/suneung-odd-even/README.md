## 패턴

1. **수학은 고정 공식**: 매년 공통과목 5지선다 중 정확히 2문항(6~15번 구간, 3·4점)만 선지를 역순으로 뒤집고, 그 두 문항의 정답이 서로 맞바뀐다(②↔④ 4회, ①↔⑤ 1회). 그래서 수학은 정답 분포가 항상 홀·짝 동일하다. 선택과목과 단답형은 손대지 않는다.
2. **바꾸는 방식은 역순이 기본**: 국어(2022~2024)·수학·한국사는 전부 선지 전체 역순 → 정답이 ①↔⑤, ②↔④로만 바뀌고 ③은 불변. 국어는 2025년부터 인접 두 선지 교환(①↔②, ④↔⑤)을 섞기 시작해 2026년엔 인접 교환만 썼다. 영어만 역순 외에 부분 교환·임의 순열을 폭넓게 쓴다(2026은 ①↔③ 교환이 8건).
3. **변경 문항 수는 줄어드는 추세**: 국어 12→12→10→5→4, 영어 16→14→14→12→12. 수학은 2개로 고정.
4. **정답은 짝을 지어 맞교환해 분포를 유지하려 한다**: 한 문항을 ④→②로 바꾸면 다른 문항을 ②→④로 바꾸는 식. 그래서 대부분 홀·짝 정답 개수가 같고, 짝이 안 맞은 해(2023 국어, 2025 국어 등)에만 분포가 어긋났다.
5. **바뀌는 문항 유형이 정해져 있다**(영어): 듣기 1~3·7~8·11~16, 독해 18~24(목적·심경·주장·함의·요지·주제·제목), 31~33 빈칸, 가끔 40~41. 선지 순서가 지문 위치에 묶인 문항(25~30 도표·내용일치·어법·어휘, 35~39 무관한 문장·순서·삽입, 42~45 장문)과 34번은 5년간 한 번도 안 바뀌었다. 국어도 지문 순서를 따라가는 선지보다 독립 진술형 선지 문항이 주로 바뀐다.
6. **배점**: 국어·영어는 2점 문항 위주, 한국사는 3점 문항 위주로 바꾼다.
7. **결론**: 홀·짝 차이는 문항 난이도가 아니라 순전히 선지 위치다. 정답 개수 분포로 "남은 답 찍기"를 할 때는 자기 형의 분포가 다른 형과 다를 수 있다(특히 국어·한국사).
